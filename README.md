# Serial Dependence Emerges from Optimizing Vision for Noise Robustness

Code and data to reproduce the results of:

> Hiroshi Higashi, Keigo Sugihara, Yuichi Tanaka.
> *Serial Dependence Emerges from Optimizing Vision for Noise Robustness* (2026).

We train recurrent autoencoders (CNN encoder → ConvGRU memory → CNN decoder) to
reconstruct clean frames of natural egocentric video (Charades-Ego) corrupted by
Gaussian noise, with **no objective referring to perceptual history**. Probing the
frozen models with Gabor and dot sequences shows that human-like **serial
dependence** emerges as a byproduct of optimizing for noise robustness: an
attractive orientation bias toward previous stimuli and a spatial "continuity
field", both strengthening with training noise. The model's temporal profile is
compared against human orientation judgments — our in-house data (N=83) and an
independent public dataset (Pascucci et al. 2019, N=20) — using a single
response-autocorrelation-corrected analysis pipeline.

This repository reproduces **Figures 2–10** and **Table 1**. (Figure 1 is a
schematic of the architecture and is not generated by code.)

## Requirements

- Python ≥ 3.12, managed with [`uv`](https://docs.astral.sh/uv/).
- A CUDA GPU (training 106 models on CPU is impractical).
- Dependencies: `torch`, `torchvision`, `numpy`, `scipy`, `pandas`,
  `opencv-python`, `matplotlib` (pinned in `pyproject.toml` / `uv.lock`).
- **For pixel-identical figure typography**, a working LaTeX installation
  (`latex`/`pdflatex`, with the `sfmath` package and a Helvetica font) is
  required, because `config.matplotlib_setup()` uses `text.usetex=True`. If you
  do not have LaTeX, set `usetex=False` in `config.matplotlib_setup` — the
  numbers are unaffected, only the fonts differ. The exact paper figures are
  also included under `figs/` for reference.

## Data

### 1. In-house human data — included

`data/bhv_hum.csv` (orientation-adjustment experiment, **N=83 after subject
exclusion**; 16,600 trials). The file contains only the participants retained
after subject exclusion (mean |err| > 39.2°); excluded participants are not
included. Relevant columns: `uid` (anonymized subject label, `sub-001` …
`sub-083`, unrelated to the original participant IDs), `err` (adjustment error,
deg), `ori` (stimulus orientation), `resp` (response), and precomputed
`rel_{1,2,3}bk` / `resp_rel_{1,2,3}bk` (relative previous stimulus / response).
The code still applies the subject-exclusion criterion, which removes no one
from this file, and the trial exclusion (|err| > 37.5°).

### 2. Charades-Ego videos — download (~11 GB)

Sigurdsson et al. (2018), *Charades-Ego*. Project page:
<https://prior.allenai.org/projects/charades-ego>

- Annotations: `https://ai2-public-datasets.s3-us-west-2.amazonaws.com/charades/CharadesEgo.zip`
- 480p videos: `https://ai2-public-datasets.s3-us-west-2.amazonaws.com/charades/CharadesEgo_v1_480.tar`

```bash
bash scripts/download_charades.sh
# -> data/CharadesEgo/CharadesEgo_v1_train.csv   (annotations)
# -> data/CharadesEgo_v1_480/<id>.mp4            (videos)
```

### 3. Pascucci et al. (2019) — download (small)

Pascucci et al. (2019), *Laws of concatenated perception*, PLoS Biology
17(3):e3000144. Raw data (CC): <https://doi.org/10.5281/zenodo.2544946>

## Reproducing the results

```bash
uv sync
bash scripts/download_charades.sh
bash scripts/download_pascucci.sh

# --- Training (GPU) ---
uv run python train_noise_grid.py     # 6 models, sigma in {0.0..0.5}  (~5 min each)
uv run python train_subjects.py       # 100 models at sigma=0.3        (heaviest step)

# --- Evaluation and figures ---
uv run python evaluate_orientation.py # Fig 2, 3, 4, 5
uv run python evaluate_position.py    # Fig 9, 10
uv run python analyze_all_corrected.py  # Fig 6, 7, 8, Table 1
```

Training the 100 subject models is the heaviest step (order of several GPU-hours;
`train_subjects.py` skips models that already exist, so it is resumable).
Figures are written to `figs/`, numerical results to `results/`.

## Method notes

- **σ = 0.3** is the showcase noise level (single-model visualizations and the
  100 subject models); the σ grid {0.0, 0.1, …, 0.5} is used for the
  noise-dependence figures.
- **Consistent, autocorrelation-corrected n-back (Fig 6–8, Table 1).** Model and
  human data pass through the *same* trial-level pipeline. Each model is turned
  into a human-format trial table: the causal reconstruction of the last frame is
  its "response" and the reconstruction of the 1-back frame is its "response to
  the previous stimulus". Following Esposito et al., the 1-back amplitude is left
  uncorrected and the response-autocorrelation correction is applied at lags ≥ 2
  (the 1-back stimulus is collinear with the 1-back response). This is what turns
  the apparent 2-back peak in the raw in-house data into a monotonic profile that
  matches the model and the public data.
